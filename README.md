# Hello World in C

A minimal C programming example that demonstrates the structure of a C program and prints a message to the terminal.

## Source

The repository's starter program is intended for learning and practicing the basic C workflow.

## Compile and Run

You need a C compiler such as GCC or Clang.

```bash
gcc hello.c -o hello
./hello
```

On Windows with MinGW:

```powershell
gcc hello.c -o hello.exe
.\hello.exe
```

If the source file has a different name, replace `hello.c` with the actual filename.

## Learning Goals

- Understand the `main()` entry point.
- Learn how to include standard library headers.
- Compile a C source file into an executable.
- Run a program from the command line.

## Next Steps

Try changing the output, declaring variables, reading input, and adding simple conditional statements and loops.
